[docs/05-product-decisions.md](../05-product-decisions.md) にある。

**POIソースのADRは番号が `docs/06-adr-poi-source.md` として独立している。** ADR 番号体系を
このディレクトリに統一する前に着手されたため。新しい ADR はここに追加すること。

## 書き方

- **状態 / 決定者 / 関連** を先頭に置く
- **背景**（なぜ決める必要があったか）→ **決定** → **影響** → **却下した案** → **未解決** の順
- 「何をしたか」ではなく **「なぜそうしたか」** を書く（CLAUDE.md のコーディング規約に準じる）
- 決定を覆すときは既存 ADR を書き換えず、**新しい ADR を追加して旧 ADR の状態を「置き換え済み」に変える**
